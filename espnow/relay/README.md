# Relay Firmware v0.1

This is the first bench-test firmware generation for the XIAO ESP32-C6 relay.

The complete modular project was also generated locally as:
Krek_Relay_ESP32C6_v0_1.zip

v0.1 intentionally uses compile-time Wi-Fi/Google settings and is not field-release firmware.

Install Arduino-ESP32 or PlatformIO with ESP32-C6 support and LittleFS.
