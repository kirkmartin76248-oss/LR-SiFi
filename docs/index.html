How to connect

1. Power the unit and let it start normally.

2. Press the XIAO BOOT button within the first 2 seconds.

3. Open the matching page in Bluefy and tap Connect.

4. Read the current settings, edit them, then save. The unit will reboot.

Do not hold BOOT while resetting/powering the XIAO; GPIO9 is also the ESP32-C6 boot-strapping pin.
