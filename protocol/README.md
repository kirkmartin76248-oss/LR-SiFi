# Shared Protocol Contracts

This directory is reserved for protocol definitions shared across firmware, installer, backend, and monitoring applications.

Contracts include:
- ESP-NOW telemetry packet
- BLE provisioning protocol
- Node persistent configuration
- Hub persistent configuration
- API request/response schema
- sensor type identifiers
- ANALOG/DIGITAL mode identifiers
- Digital Active Level
- Node-wide Sensor Delay
- configuration/version identifiers

Changes here require checking Node firmware, Hub firmware, backend/Apps Script, Installer, and Monitoring Portal.
