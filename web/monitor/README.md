# Krek Labs Monitoring Portal

Customer-facing web/PWA application.

Target URL:

`https://monitor.kreklabs.com`

Hosting target: GitHub Pages.

This application is the customer monitoring interface. It must not contain secrets or direct credentials for customer Google Sheets.

Primary areas:
- Dashboard
- Locations
- Alerts
- Settings

Data access occurs through the protected backend/API contract defined by the architecture documents.
